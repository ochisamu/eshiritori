# 統合起動・コード不要の会話UX

2026-10-31。ユーザーの追加依頼により、ゲーム・会話API・ホスト設定を同じサーバーへ統合。従来の会話サーバーを別に起動する操作は不要です。

## 使い方

npm run buildはフロントとサーバーをビルドします。npm start／npm run serveは同じ統合サーバーを起動し、既定はhttp://localhost:4173です。WSLのUNCフォルダからWindowsで起動する場合はnode tools/start.mjsを使えます。

.envがあれば使用します。ホストPCの「会話する」→「ホスト設定」でもキーを入力できます。キーはlocalhostかつループバック接続だけで設定可能。ブラウザの保存領域には残さず、既存値を返すAPIもありません。任意保存先の.voice/settings.jsonはGit・配布から除外、POSIXではファイル0600／フォルダ0700です。保存済み設定が.envより優先します。

このPCは同一OriginのPOSTで自動認可。LANはHTTPS設定後、ホスト限定画面で作る5分・1回限りのQR／リンクを開く方式です。フラグメントのトークンは認可処理前にURLから消し、Referer／HTTPアクセスログへ送りません。LAN端末のキー設定・読み出しは拒否します。従来の6桁コード入力はGUIからなくしました。

タイトルでは無効な開始ボタンを置かず、「時間なしの対戦を準備」で盤面を作り、会話パネルを開きます。開始中は音声準備・マイク許可待ち・API接続を表示。マイクが返らない場合は20秒で案内し、遅れて取得したストリームも閉じます。

[起動・LAN・証明書ガイド](../../docs/voice-opponent.md)／[初回の実API・自然さ検証](../voice/verification.md)。

## 確認

- 単体204件成功。ループバック・Host・Origin・転送ヘッダー・CSRF、キー非公開、保存権限、QR生成、リンクの一回利用と期限を検査。
- UIは20種類×3エンジンの60種類を確認。対戦準備、キー入力の消去とブラウザ非保存、マイク拒否／許可待ち、LANリンク自動認可とフラグメント消去、共有ヒント、固定画面を含みます。
- 初期のUI試験ではService Workerが模擬APIを迂回。UI試験をキャッシュから隔離し、PWAは別の実Service Worker試験12件ですべて成功。WebKitの未応答マイクも専用のMediaDevices差し替えで確認。
- 実APIの追加試験は合成日本語入力。最初は追加ヒントのモード取り違えがあり、明確な要求のツールとenumを要求された段階に限定。再試験77.52秒、音声69秒で正常終了し、拒否非消費・再読非消費・第3段階・REFERENCE不変更、非ゼロPCM再生を確認。実行時例外0。
- 今回の実API試験分の推定はUS 0.111240ドル。前回の保守的集計を含む自動試験分は約US 2.436ドルで、指定US$5以内。請求明細とは未照合。人の手動試遊分は別途確認が必要です。
